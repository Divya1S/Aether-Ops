AetherOps

An autonomous incident-remediation & change-intelligence platform — agents diagnose from cited evidence, plans compile from a vetted action catalog, humans approve at policy gates, and every quality claim below is a number measured by the repo's own CI. Pure Python stdlib; runs anywhere; costs nothing.

Engineered like software, because it is

 REST API      POST /v1/incidents → PAUSED at gate → POST .../approvals
               {"decision":"approve"} → SUCCEEDED + postmortem  (bearer auth)
 MCP server    python3 -m aetherops.mcp — JSON-RPC/stdio tools for any
               MCP client: search_runbooks · list_runbooks · eval_summary
 Docker        docker compose up — same API, containerized, healthchecked
 Security      OWASP LLM Top 10 mapped; injection attack lives IN the
               test suite (LLM01) and cannot mint actions (LLM06)
 Governance    hash-chained audit ledger · versioned prompts w/ lockfile
               · schema-validated agent outputs · saga rollback
